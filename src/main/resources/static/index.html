AI Prediction

AI予想

Gemini と Claude に同じレースを予想させ、2つの AI の勝率を平均した「総合予想」を出します。出馬表にいる馬が名鑑に載っていれば、戦績・血統・能力値も AI に渡して予想の材料にします。

AI 予想は、パソコンで起動したアプリ版 (run.bat / ./run.sh) でだけ使えます。Web 版では API キーを安全に保管できないためです。

          オッズは同じレースを 2 万回走らせた確率から、JRA と同じ控除率 (単勝 20%〜3連単 27.5%) で計算しています。そのため本物と同じく、どの馬券も平均すると賭け金の 72.5〜80% しか戻りません。お金はこの画面の中だけの仮想のものです。

          着順は能力値・脚質・ペース・距離と馬場の適性・乱数から決まります (計算は Zig)。能力値は Wikipedia 記載の戦績から算出した参考値です。
